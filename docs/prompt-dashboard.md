# NGMS Prompt Dashboard\n\nMVP route: `/prompt-dashboard`.\n\nUses the existing NGMS Next.js app and Supabase project. Database tables: `prompt_categories`, `prompts`, `prompt_users`, `prompt_activity_logs`. The existing `settings` table is reused.\n\nThe MVP builds reusable prompts from Supabase templates, substitutes variables, supports editing/copying/WhatsApp sharing, and records activity. AI-provider generation is intentionally separated for the next build chain.
